Terminal Cheat Sheet

Windows · PowerShell
The everyday commands — find your way, make folders, move files. Python for Biologists.

Open the terminal

  1. Press the Win key, type PowerShell, hit Enter
  2. (or right-click Start → Terminal)
  3. Use PowerShell — not the old Command Prompt (cmd)
You'll see a prompt like: PS C:\Users\you>

Find your way

pwd            # where am I?
ls             # list files  (or: dir)
ls -Force      # include hidden files
cd folder      # go into a folder
cd ..          # go up one level
cd ~           # go home
clear          # clear the screen (or cls)
cat file.txt   # show a file's contents

Make things

mkdir data       # make a folder
mkdir a\b\c      # nested folders
ni notes.txt     # make an empty file

Paths use \ (backslash): cd Documents\data

Copy · move · delete

cp a.txt b.txt   # copy a file
cp -r dir1 dir2  # copy a folder
mv a.txt data\   # move a file
mv old.txt new.txt # rename a file
rm file.txt      # delete a file
rm -r folder     # delete a folder

Careful: rm is permanent — it does not use the Recycle Bin.

Help & shortcuts

Get-Help ls    # help for a command
ls -?          # quick usage

Tab auto-completes names · ↑ ↓ scroll previous commands

Pro tip

A nicer terminal — Warp

warp.dev is a free, modern terminal (same on Windows & Mac) with autocomplete and a built-in AI helper — a teacher, not a crutch. Download it, choose Skip for now (no account needed). Every command above works exactly the same in it.
