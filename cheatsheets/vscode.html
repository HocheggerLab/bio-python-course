VS Code Cheat Sheet

Mac & Windows
Set up once, then write → run → fix. Python for Biologists, Lab 3.

Set up — once

  1. In a terminal, before VS Code: uv python install 3.14, then uv run python --version → 3.14
  2. File → Open Folder → New Folder → open it. Always a folder, never a lone file.
  3. "Do you trust the authors?" → Yes — it's your own folder.
  4. Extensions sidebar → search Python → Install (publisher: Microsoft).
  5. Command Palette → Python: Select Interpreter → the 3.14 with uv in its path.
Not in the list? Enter interpreter path: ~/.local/bin/python3.14 (Mac) · %USERPROFILE%\.local\bin\python3.14.exe (Windows)

Run your code

  • ▶ (top right of the editor) — runs the open file
  • Or open the terminal Ctrl ` and type:
uv run hello.py     # the Lab 2 way

Both should use the same Python — the status bar (bottom right) shows which: it should say 3.14.

Read the squiggles

  • Red underline — an error; it won't run like this
  • Yellow underline — a warning; it runs, but look
  • Hover over it to read the message
  • All of them at once: Problems panel ⇧⌘M / Ctrl+Shift+M
  • A white dot on the file tab = unsaved changes

In the Command Palette

Open it, then start typing — you never need to remember the menus.

Python: Select Interpreter

After the last one, code . in a terminal opens that folder in VS Code.

When it goes wrong

  • No ▶ button? Is the Python extension installed, and does the file end in .py?
  • Old output? Save first — or turn on File → Auto Save.
  • Different results from ▶ and uv run? Wrong interpreter — check the status bar, then Select Interpreter.
  • File not found? The terminal runs from the folder you opened — open the project folder, not your whole Documents.
